# 스테이지 배경 아트 방향 (초안, 승인 전)

배경은 이미지 한 장이 아니라 **PixelLab 구조물(투명 스프라이트) 여러 개를 레이어로 배치**해서 만든다.

## 무대 기준 (코드에서 확인한 값)

- 시점: **사이드뷰**. 플레이어는 왼쪽, 몬스터는 오른쪽 (`AreaView`)
- 발 높이: 화면 아래에서 42% (`AreaView.GroundViewY`). 그 아래쪽은 전투 HUD가 차지함
- 캐릭터 / 몬스터: 64~96px, **PPU 64**, Point 필터, sortingOrder 10
- 몬스터 화풍: 진한 외곽선, 디테일한 음영, 채도 높은 강조색 (예: 마그마 골렘)

## 테마 (DungeonServer.TierThemeNames)

| 계층 | 테마 | 핵심 소재 |
|---|---|---|
| 1 | 슬라임 왕국 | 점액 웅덩이, 끈적한 바위, 슬라임 왕궁 잔해, 젤리 결정 |
| 1 | 용암 지대 | 현무암 기둥, 흑요석 바위, 용암 웅덩이, 화산 원경, 식은 마그마 광맥 |
| 2 | 리자드의 늪 | 늪지 거목, 뿌리, 갈대, 토템, 물웅덩이, 수몰 유적 |
| 2 | 침묵의 숲 | 어두운 고목, 이끼 바위, 버섯, 안개 낀 원경 |
| 3 | 정령계 | 떠 있는 수정, 원소 제단, 부유 섬, 빛기둥 |

## 레이어 (뒤에서 앞 순서)

| 레이어 | 내용 | 만드는 법 | sortingOrder |
|---|---|---|---|
| Sky | 하늘 그라데이션 2색 | 코드 (생성 안 함) | -100 |
| Far | 원경 실루엣 (산 / 숲 / 부유 섬) 2~3개 | PixelLab, 256px, 채도·대비 낮게 | -80 |
| Mid | 큰 구조물 (기둥, 거목, 유적) 3~4개 | PixelLab, 128~192px | -60 |
| Ground | 땅 띠 (가로로 이어 붙임) 1~2종 | PixelLab, 128×64 타일 | -40 |
| Near | 발밑 소품 (바위, 풀, 웅덩이) 3~4개 | PixelLab, 48~96px | -20 |
| (캐릭터) | | | 10 |

## 공통 생성 규격

- 도구: `create_object_pro_flash`, `view="side"`, `n_directions=1`, 투명 배경
- 크기: 4의 배수, PPU 64 그대로 (원경만 배율을 키워도 됨)
- 외곽선: 근경·중경은 몬스터처럼 진한 외곽선, 원경은 외곽선 없이 흐리게
- 가독성: 배경은 몬스터보다 **채도·대비를 낮게**. 캐릭터가 서는 42% 높이 띠 근처에는 큰 구조물을 두지 않음
- 스타일 통일: 테마마다 첫 구조물을 확인받은 뒤 그 그림을 `style_image`로 다음 생성에 계속 넣음
- 저장: `Assets/Terminus/Art/Backgrounds/<테마키>/` (테마키: slime, lava, lizard, forest, spirit)

## 비용 추정

테마당 구조물 약 10개 × 5~9회 = 약 60회. 5개 테마를 다 하면 약 300회 (잔여 4,789회).

## 진행 순서

1. 용암 지대로 시범 진행: 구조물 1개를 만들어 확인 → 나머지 생성 → Unity에 배치해서 화면 확인
2. 통과하면 나머지 4개 테마도 같은 규격으로 진행
3. 테마 → 배경 프리셋(ScriptableObject) 연결, `AreaView`가 테마에 맞는 배경을 깔게 함
